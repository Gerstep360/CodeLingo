# 05-permutaciones

Clase modular de CodeLingo para **Permutaciones**.

Modelo mental:
- PERMUT = NO tengo `i`.
- El `for` siempre empieza en `k=0`.
- SR = `!L1.contains(L2.get(k))`.
- CR = libre, sin filtro.
- Ambas conservan `add → recursión → removeLast`.

`base.json` enseña la lógica común de la familia.
Los archivos de `exercises/` contienen los algoritmos Java canónicos completos.
