# 04-combinaciones

Clase modular de CodeLingo para **Combinaciones**.

Modelo mental:
- COMBI = tengo `i`.
- SR = llamada con `k+1`.
- CR = llamada con `k`.
- Ambas conservan `add → recursión → removeLast`.

`base.json` enseña la lógica común de la familia.
Los archivos de `exercises/` contienen los algoritmos Java canónicos completos.
