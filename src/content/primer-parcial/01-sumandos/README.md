# 01-sumandos

Contenido modular de CodeLingo para la clase **Sumandos**.

Estructura:

- `class.json`: metadatos y modelo mental de la clase.
- `base.json`: algoritmo base canónico.
- `shared/suma.json`: auxiliar `suma`.
- `exercises/diferentes.json`: variante `k+1`.
- `exercises/pares.json`: filtro `k%2==0` y llamada canónica `k+1`.
- `exercises/rango.json`: limita el `for` hasta `b`.

Todos los `code.target` conservan la lógica del archivo canónico `ExamenVargas.java`.
